## The lesson that cost this session, and it is one lesson four times

**Every guard I wrote checked something one seam away from the defect, and each
fix relocated the seam instead of closing the class.**

1. cycle 1 — a **value** check: `len(x)==len(set(x))` on a set-derived list.
2. cycle 2 — a **definition** check: `FLAG_ARMS[0] == ("baseline", {})`. A
   downstream injection doesn't touch a definition.
3. cycle 3 — a **behavioural** check **on the wrong variable**. `delta = arm −
   baseline`; I guarded the baseline feeding *one arm* and left the row every
   delta is subtracted *from* unguarded. Two structurally identical call sites;
   one guarded is not guarded.
4. and an **overclaim** about what the check covered, shipped in a code comment
   *and* both artifacts: *"an injection anywhere in the replay path makes these
   diverge."* It didn't.

Concretely, for next time:

- **Guard the value the CONCLUSION consumes**, not the one nearest your fix.
  Ask: "if this number were wrong, which variable would be wrong?" — guard that.
- **Grep for sibling call sites before declaring a seam covered.** Two identical
  `replay_session(...)` calls existed; I read one.
- **A guard licenses only the variable it compares**, never the path you
  describe it as covering. Write the scope narrowly in the comment.
- **A fixture is DATA, so an AST census cannot see it.** The fixture backing
  four cells had no cell until the evaluator emptied it.
- **Never splice a "verbatim" capture.** Two non-reproducing numbers this
  session, both mine; regenerate the whole block from one run.
- **Run mutation cells at the PUBLISHED parameters.** Kill/survive was
  cycle-count dependent — a poison survived at 4 cycles and died at 20.
