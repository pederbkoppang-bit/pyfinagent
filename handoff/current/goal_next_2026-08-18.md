## The lesson that cost the most time

Three of four evaluations blocked on **guard vacuity, never on product
defects** — every verdict said the shipped code was correct. Before spawning
a Q/A, for each criterion that says MUTATION, actually run the named mutation
against the REAL file and the REAL suite and require a non-zero exit. "The
mutant is non-equivalent" is a weaker claim than "the suite goes red", and only
the second is what failed. Specifically: a test that imports a module never
runs its `__main__`, a fixture that names a file it never creates cannot
represent the failure, and a source scan cannot observe runtime behaviour.
